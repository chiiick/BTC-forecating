# Results

Fresh results generated by the refactored pipeline will be written here by:

```bash
python src/train.py
```

Generated files include `test_metrics.csv`, `backtest_metrics.csv`, model predictions, and a run configuration file.

## Archive

`archive/` contains values transcribed from the original final course presentation. They are preserved only as historical project records.

The refactor corrects the future-target alignment used in the original notebook. In the original implementation, the longer-horizon rolling target could include returns that were already inside the model input window. This can inflate 4h/6h direction accuracy. For that reason, archived presentation metrics should **not** be treated as validated performance of the cleaned pipeline.
