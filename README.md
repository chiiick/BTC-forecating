# BTC-forecating
# Multi-Horizon BTC/USDT Forecasting with Deep Learning

Deep learning-based forecasting of BTC/USDT future returns
using GRU, LSTM, TCN, and Transformer models.

## Highlights

- 2 years of BTC/USDT 1-hour OHLCV data
- 240-hour historical input window
- Multi-horizon prediction: 2h / 4h / 6h cumulative returns
- GRU, LSTM, TCN, and Transformer comparison
- MAE, RMSE, Direction Accuracy evaluation
- Simple long/short backtesting
